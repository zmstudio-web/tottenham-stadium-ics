Add it

  • iPhone/iPad: Settings → Calendar → Accounts → Add Account → Other → Add Subscribed Calendar → paste the URL.
  • Google Calendar: Other calendars → + → From URL → paste.
  • macOS Calendar: File → New Calendar Subscription → paste.

Times for concerts are approximate. Always check official sources before relying on any entry.
