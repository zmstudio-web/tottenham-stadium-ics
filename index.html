Add it as a live subscription

  • iPhone/iPad: Settings → Apps → Calendar → Accounts → Add Account → Other → Add Subscribed Calendar → paste the plain URL. (Tapping the webcal link above does this for you.)
  • macOS Calendar: File → New Calendar Subscription… → paste the plain URL → on the next screen set Location to your iCloud account (not "On My Mac") so it syncs to all your devices, and set Auto-refresh to "Every day". Do not just double-click the .ics file — that imports a static copy instead.
  • Google Calendar: Other calendars → + → From URL → paste the plain URL.

Already imported a one-off copy by mistake? Delete that calendar (or the individual events) and re-add using the steps above — a subscribed calendar shows up as its own separate calendar named "Tottenham Hotspur Stadium events" in your calendar list, refreshes itself, and its events can't be edited individually.

Times for concerts are approximate. Always check official sources before relying on any entry.
